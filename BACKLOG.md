# Future Capabilities & Backlog

This backlog tracks architectural ideas, integrations, and capabilities that are **intentionally NOT implemented yet**.

In accordance with our core operating principles (*"Practical over complex"*, *"Do not build functionality before it is needed"*, and *"Do not move to the next stage until the current stage works"*), these items remain deferred until their respective build phases are reached.

## Deferred Items

1. **Structured Agent Communication**
   - Formalized inter-agent messaging protocols, exchange schemas, and handoffs.
2. **Decision System**
   - Explicit decision-making matrices, consensus models, and escalation pathways.
3. **JesterBridge Audit**
   - Comprehensive technical inspection of the existing JesterBridge codebase and capabilities.
4. **Bridge MVP**
   - Minimal viable bridge implementation connecting company operations to target environments.
5. **Antigravity ↔ Bridge Integration**
   - Direct integration between the Antigravity development runtime and JesterBridge.
6. **Persistent Company Memory**
   - Long-term storage, cross-session context retention, and vector/relational memory stores.
7. **Permissions & Access Control**
   - Role-based access boundaries restricting agent capabilities, file modifications, and execution rights.
8. **Human Approval System**
   - Interactive checkpointing and explicit approval gates for high-impact actions.
