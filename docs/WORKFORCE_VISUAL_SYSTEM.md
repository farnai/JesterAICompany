## 1. Core Product & Visual Philosophy

### 1.1 The Breakthrough: The "Infographic Workforce"
Jester AI Company is not an agent configuration tool, not a developer IDE, not a dark SaaS console, and not a static dashboard. It is an **interactive AI workforce platform**.

The foundational emotional promise to the human Owner is:
> **"I am building and running an actual company. I have hired real, distinctive professionals who communicate, delegate, build, verify, and deliver real results."**

### 1.2 The Graphic Metaphor
Rather than defaulting to standard SaaS cards in isolated grids (`Card + Card + Card + Table`), Jester AI Company adopts the sophisticated visual grammar of:
- **Data integration infographic vectors**
- **Cloud data exchange and workflow diagrams**
- **Connected node architectures & system process flows**
- **Clean vector business illustrations**

**The Critical Reinterpretation:**  
We take this clean, connected infographic language and **center it entirely around PEOPLE, WORK, COLLABORATION, and RESULTS**.

```
    TRADITIONAL SAAS DASHBOARD                    JESTER WORKFORCE INFOGRAPHIC
┌─────────────────────────────────┐           ┌───────────────────────────────────┐

## 2. The Core Visual Grammar

The visual syntax of the entire interface is defined by five foundational primitives:

$$\mathbf{PERSON} + \mathbf{CONNECTION} + \mathbf{WORK} + \mathbf{FLOW} + \mathbf{STATE}$$

1. **PERSON (The Human Node):** A stylized vector portrait (head & shoulders) enclosed in an identity ring, communicating role, current focus, and presence.
2. **CONNECTION (The Relationship):** Clean vector conduits with directional flow indicators showing who delegates to whom, who is handing off to whom, and where information is traveling.
3. **WORK (The Commission):** Floating visual cards representing Projects, Goals, and Tasks anchored directly between the people executing them.
4. **FLOW (The Momentum):** Animated pulse packets or active path highlights (in warm Carrot Orange `#F95924`) that physically travel between nodes during execution, delegation, and review.
5. **STATE (The Operational Truth):** Micro status badges (`● BUILDING`, `○ WAITING`, `🛡️ VERIFYING`, `✓ PASSED`) that visually alter the node's aura and ring without changing its underlying identity.

│   #168050                   #D97706                  #D9383A (Crimson) │
└────────────────────────────────────────────────────────────────────────┘
```

### Color Discipline Rules:
- **No Rainbow Colors:** Employees are NOT assigned arbitrary pastel colors. Character distinction comes from facial features, hair, clothing, and posture—not color-coding people like children's toys.
- **Orange is Action:** `#F95924` is reserved exclusively for the primary flow of active work, active connections, and key interactive touchpoints.
- **Semantic Restraint:** Green (`#168050`) is strictly used for successful QA verification and completed milestones; Amber (`#D97706`) for waiting or handoff states; Crimson (`#D9383A`) for verification defects.

## 4. Character & Avatar Design System

### 4.1 Avatar Art Direction Guidelines
- **Portraits Only:** Head, neck, and shoulders portrait framing. **Zero full-body cartoon characters.**
- **Sophisticated Vector Style:** Clean geometric line work, subtle color blocking, modern contemporary apparel, distinctive silhouettes.
- **Human & Professional:** They look like real technology and creative professionals in their 20s, 30s, and 40s.
- **Expressive but Restrained:** Subtle facial expressions (calm, focused, skeptical, energetic), recognizable hairstyles, contemporary eyewear, and accessories.
- **Strictly Prohibited:** Chibi, kawaii, children's cartoon aesthetics, Pixar 3D models, anime, full-body cartoon people, emoji icons, generic stock avatar packs.

## 5. The Living Network Company Map

The **Company Map** departs from traditional static org charts and transforms into an **interactive workflow network**.

### 5.1 Structural Composition
The map is laid out as a multi-tier directed graph that connects the Founder to the workforce and active deliverables:

```
                            [ YOU ]
                     ( FOUNDER / OWNER )
                              │
                    [ Vision & Approval ]
                              │
                              ▼
                           [ CEO ]
                   ( STRATEGIC COORDINATOR )
                              │
        ┌─────────────────────┼─────────────────────┐
        │ [Task Brief]        │ [Requirements]      │ [UX Specs]
        ▼                     ▼                     ▼
 [ DEVELOPER ]          [ PRODUCT ]              [ UX ]
  ( Building )           ( Scoping )           ( Designing )
        │
    [Commit Patch]
        │
        ▼
   [ ARTIFACT ]
(nav_header.html)
        │
   [Verify Code]
        │
        ▼
     [ QA ]
  ( Verifying )
        │
    [PASS / FAIL]
        │
        ▼
   [ RESULT ]
 ( Verified Build )
```

### 5.2 Network Infographic Elements
- **Nodes (The Anchors):** Circular avatar hubs with dynamic outer halo rings.
  - Active: Glowing Carrot Orange halo (`#F95924`) with animated micro-pulse.
  - Waiting / Reviewing: Soft Amber or Teal halo.
  - Idle: Subtle 1px sandstone ring (`#E2E0D8`).
- **Conduits (The Paths):** Crisp SVG paths with subtle rounded elbows (radius 16px).
  - Resting paths: Light neutral lines (`1.5px solid #E8E5DD`).
  - Active paths: Energetic orange lines (`2px solid #F95924`) with animated SVG dash-arrays simulating information packets traveling between colleagues.
- **Data Waypoints (Action Chips):** Floating micro-labels positioned along connection lines indicating the action taking place (e.g. `Delegates Task`, `Emits Artifact`, `Runs Test Suite`).

## 7. Project & Task Execution Flows (With Remediation Loops)

Real work is rarely a straight line. The infographic visual language natively supports **handoffs, loops, and remediation cycles**.

### 7.1 The Standard Delivery Flow
1. **Owner Directs:** Founder assigns mission (`"Build Restaurant Website"`).
2. **CEO Orchestrates:** Connection line lights up from CEO $\rightarrow$ Developer (`Task: Responsive Header`).
3. **Developer Builds:** Developer node turns `● ACTIVE`. A document node `header.html` materializes on the canvas.
4. **Handoff to QA:** An orange connection line routes the artifact from Developer $\rightarrow$ QA.
5. **QA Inspects:** QA node enters `🛡️ VERIFYING`.
6. **Pass & Deliver:** Verification passes $\rightarrow$ connection illuminates in Forest Green $\rightarrow$ `✓ Result Node` is stamped and presented to Founder for approval.

### 7.2 The Remediation Loop (When Verification Fails)
When QA discovers a defect, the system visually handles it with dignity and precision:
```
Developer Node ──[Code Patch]──→ Artifact ──→ QA Node (Verifying)
      ▲                                            │
      │                                       [FAILED: Exit 1]
      │                                            │
      └───────── [Defect Trace & Line 42] ─────────┘
                 (Amber/Crimson Return Flow)
```
- A dashed amber/crimson conduit routes back from QA directly into Developer's desk.
- Developer's status transitions: `● FIXING DEFECT: Line 42 Viewport Overflow`.
- A contextual dialogue bubble appears:  
  *QA:* `"Mobile navigation overflows at 320px. Trace in report."`  
  *Developer:* `"Found it. Adjusting media query padding now."`
- Once Developer recompiles, the patch flows forward to QA for re-verification.

## 9. Animation & Motion Design Tokens

All animations are designed to feel like **subtle electrical data pulses through a warm architectural circuit**:

1. **Pulse Packets (Active Conduits):**  
   SVG `stroke-dasharray: 6, 12` with `animation: flowDash 1.8s linear infinite`. Represents data/work flowing along a connection line.
2. **Node Ambient Breathing:**  
   Active employee node halos gently expand and contract: `transform: scale(1.03)` with `opacity: 0.9` over a smooth 3.5s sinusoidal curve.
3. **Dialogue Pop-in:**  
   Contextual speech chips glide in from their speaker's node: `transform: translateY(6px)` $\rightarrow$ `translateY(0)` with `opacity: 0` $\rightarrow$ `1` over 220ms spring ease.
4. **Verification Stamp Settling:**  
   When QA outputs exit code 0, the green verification seal stamps into place with a crisp 180ms scale-down (`1.15` $\rightarrow$ `1.0`), evoking a physical seal of approval.

## 10. Design Checklist & Quality Gates

Before any component is integrated into the final Control Center redesign:
- [x] **No Card Grids:** Interface is organized around interconnected nodes and workflows, not disconnected boxes.
- [x] **Avatar Quality:** Avatars are crisp, distinctive vector portraits (head & shoulders) with personal character; zero generic stock icons or children's cartoons.
- [x] **Clear Hierarchy:** Founder sits above CEO; CEO coordinates the team; active employees are distinct from idle ones.
- [x] **Backend Decoupling:** The visual flow strictly interprets real `Task`, `TaskRun`, and `VerificationResult` backend data without driving backend logic.
- [x] **Evidence Accessible:** Monospace logs, exit codes, and diffs are two deliberate clicks away via the Level 3 drawer.
